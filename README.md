# Project Context Exporter

Instantly package your project's text files into a single, AI-ready block. Perfect for pasting into Claude, ChatGPT, Gemini, and more.

Select a project folder and the app scans it entirely in your browser, filters out clutter (`node_modules`, `.git`, build output, binaries, lockfiles, etc.), and concatenates the remaining text files into one block you can copy to your clipboard. No files are uploaded anywhere.

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`
